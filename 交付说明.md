# 账目配平工具交付说明 / Delivery Note

## 中文

### 项目状态

本轮改造已完成并通过验收，旧版 `project-centered` 账目配平工具已成功改造成新版 `entry-centered` 本地小工具。

### 本轮完成内容

- 保留了原有入口、主窗口框架、SQLite 存储模式、设置页与基础页面结构
- 将核心数据模型改为以 `entries.remaining_amount` 为中心
- 新增 `match_records`、`match_links`，支持匹配记录落库
- 导入器已支持：
  - 明细分类账读取
  - 科目字段向下继承
  - `row_type` 识别
  - `amount_side / original_amount / remaining_amount` 初始化
- 匹配引擎已支持：
  - `1:1` 完全匹配
  - `1:1` 部分匹配
  - `1:N / N:1` 组合匹配（最多 3 条）
  - 循环匹配直到无新增结果
- AI 已调整为“金额候选成立后的语义辅助”，不再主导主流程
- 结果页已改为分录级三栏视图，支持查看未配平分录、候选建议、已匹配记录
- 已支持手工确认匹配与取消匹配

### 验收结论

本轮验收通过，已确认以下事项：

- Repository 验证通过
- Importer 验证通过
- Matching Engine 验证通过
- AI 辅助验证通过
- UI 人工验收通过，包括：
  - 导入成功并进入结果页
  - 左栏显示 `原始 / 已匹配 / 剩余 / 状态`
  - 默认只显示 `remaining_amount > 0` 的分录
  - 右栏出现自动匹配记录
  - 取消匹配后 `remaining_amount` 能恢复

### 当前可交付结论

当前版本已满足“可运行、可测试、可演示”的交付要求，可作为本地轻量账目配平工具继续使用与迭代。

## English

### Project Status

This round of refactoring has been completed and accepted. The legacy `project-centered` reconciliation tool has been successfully transformed into a new local `entry-centered` utility.

### What Was Delivered

- Preserved the existing entry point, main window shell, SQLite storage pattern, settings page, and basic page structure
- Reworked the core data model around `entries.remaining_amount`
- Added `match_records` and `match_links` to persist reconciliation actions
- The importer now supports:
  - detailed ledger file loading
  - downward inheritance for subject fields
  - `row_type` detection
  - initialization of `amount_side / original_amount / remaining_amount`
- The matching engine now supports:
  - `1:1` full match
  - `1:1` partial match
  - `1:N / N:1` combination match, up to 3 linked rows
  - repeated matching cycles until no new matches are found
- AI has been repositioned as a semantic assistant only after amount-based candidates are formed
- The results page has been rebuilt into an entry-level three-pane view
- Manual confirmation and match cancellation are now supported

### Acceptance Result

This delivery passed acceptance. The following items were verified:

- Repository verification passed
- Importer verification passed
- Matching engine verification passed
- AI assistance verification passed
- UI manual acceptance passed, including:
  - successful import and navigation to the results page
  - left pane displays `original / matched / remaining / status`
  - default filter shows only entries with `remaining_amount > 0`
  - right pane shows auto-generated match records
  - cancelling a match correctly restores `remaining_amount`

### Delivery Conclusion

The current build meets the delivery expectation of being runnable, testable, and demo-ready, and can continue to be used as a lightweight local reconciliation tool for further iteration.
